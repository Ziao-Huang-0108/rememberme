# CloudBase 配置清单（Remember Me）

环境 ID：`remember-me-d1gmd5iiu9d88c58a`（上海）

## 1. 安全域名（必须，不然网页连不上）

打开 [云开发平台 → 环境配置 → 安全配置](https://tcb.cloud.tencent.com/)：

- 添加 `localhost`
- 添加 `127.0.0.1`
- 以后部署了再加正式域名

改完大约等 10 分钟生效。

## 2. 打开登录方式

在 **身份认证 → 登录方式**：

- 先打开 **匿名登录**（现在用「填昵称进入」测全家同步）
- 微信开放平台批下来后，再打开 **微信开放平台登录**，填 AppID / AppSecret

## 3. 建三张表（文档型数据库）

在 **文档型数据库** 里新建集合（名字必须一致）：

| 集合名 | 用途 |
| --- | --- |
| `households` | 家庭 |
| `members` | 家庭成员 |
| `items` | 物品 |

权限可以先设成：**仅登录用户可读写**（等熟悉后再收紧）。

## 4. 微信登录（可后做）

1. [微信开放平台](https://open.weixin.qq.com/) 申请网站应用  
2. 在 CloudBase 登录方式里启用并填写密钥  
3. 把网站回调域名配好  
4. 告诉我，我再把按钮从「暂未开通」改成真正扫码登录  

## 5. 本地怎么开

```bash
npm run dev
```

浏览器打开终端里的地址。第一次会进登录页。
