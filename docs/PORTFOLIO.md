# Remember Me 作品集素材

> 这份文档是作品集的“原材料”，随项目迭代持续更新。详细的过程记录见 [DEVLOG.md](DEVLOG.md)。

## 1. 项目背景与痛点

家里的东西越买越多，常见的几种情况：

- **忘了放在哪**：上次买的备用电池、药、充电线，要用的时候翻遍柜子也找不到。
- **过期了才发现**：药品、调料、护肤品放着放着就过期了，等发现时只能扔掉。
- **重复购买**：不知道家里还有存货，于是又买了一份。
- **信息不共享**：东西是一个人买的、放的，其他家人都不知道。

## 2. 目标用户

| 角色 | 特点 | 主要需求 |
| --- | --- | --- |
| 采购者（经常买东西的人） | 会主动录入 | 录入要快，字段不要太多 |
| 使用者（其他家人） | 很少录入，偶尔查找 | 能快速搜到东西在哪 |
| 长辈 | 不熟悉复杂操作 | 字大、颜色直观、步骤少 |

（画像会根据家人试用后的反馈继续补充。）

## 3. 核心功能

- 记录物品：名称、价格、功能/用途、购买日期、过期日期、放置位置、备注、照片、类别
- 过期颜色提示：红 / 橙 / 黄 / 绿四档，同一档内越接近过期颜色越深，已过期单独标出
- 查找：按过期远近排序，按过期情况、类别筛选（按上传人筛选等全家共用后开放）

## 4. 关键设计决策

| 决策 | 选择 | 理由 |
| --- | --- | --- |
| 产品形态 | 手机网页（PWA） | 不用上架审核、跨平台、一个链接就能分享给家人 |
| 数据存储 | 腾讯云 CloudBase + PostgreSQL | 国内可用；体验版用 SQL 库存家庭与物品 |
| 登录 | 用户名 + 密码 | 不要微信执照、不用短信；家人账号在控制台创建，网页只登录不注册 |
| 剩余天数的更新方式 | 打开时实时计算 | 不依赖定时任务，数字永远准确 |
| 颜色分档 | 30 天 / 半年 / 一年三个分界点 | 对应“马上处理 / 近期留意 / 心里有数 / 不用操心”四种行动 |
| 颜色深浅 | 同档内越接近过期越深 | 让最急的东西最显眼 |
| 已过期状态 | 单独一档，写明过期天数 | 原始规则没覆盖，却是最需要处理的情况 |
| 界面风格 | 温馨暖色、手机优先 | 大触控、主操作不被悬浮控件挡住；过期颜色仍表达紧急程度 |
| 上线方式 | PWA + CloudBase 静态托管 | 国内访问稳；默认域名通常已在白名单，少踩跨域套餐坑 |

## 5. 迭代历程

| 版本 | 内容 | 关键变化 |
| --- | --- | --- |
| v0 | 单机原型「记得住」 | 个人工具，只存在本机 |
| v0.1 | 重新定位为全家共享 | 确定字段、颜色规则、技术方案 |
| v0.2 | 本地清单可用 | 增删改、颜色条、按剩余天数排序；数据暂存本机 |
| v0.3 | 界面重做 + 照片类别筛选 | 活泼风格；可拍照；按类别/过期筛选 |
| v0.4 | 赤柴吉祥物 + 动态波点 + 自家歌 | 标题旁小六；进门尽量播放《4am》，可静音 |
| v0.5 | CloudBase 家庭共享 | 邀请码加入；云端同步 |
| v0.6 | 用户名密码 + PostgreSQL | 体验版走 SQL；网页去掉无效注册 |
| v0.7 | PWA 可安装 | 可加到手机主屏幕；准备部署给家人 |
| v0.8 | 前端改 CloudBase 静态托管 | 不用 Vercel；国内更稳，登录少被域名白名单卡住 |
| v0.9 | 手机优先温馨 UI | 修音乐挡保存；触控与配色按移动端规范收紧 |
| v0.9.1 | 音乐键可拖贴边 | 🎵 可拖、贴边半藏；蜜桃陶土点缀、彩色波点恢复 |

## 7. 反思与下一步

- 已能本地登录、建家庭、记物品；前端改走 CloudBase 静态托管后，收集家人真实反馈。
- 网页自助注册被腾讯云拦住，家庭场景用控制台开号更合适，但要提前帮长辈建好账号。
- Vercel 免费域名国内不稳，且自定义跨域白名单可能要付费，故前端托管与后端同落腾讯云。
