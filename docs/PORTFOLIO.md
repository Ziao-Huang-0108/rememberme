# Remember Me 作品集素材

> 这份文档是作品集的“原材料”，随项目迭代持续更新。详细的过程记录见 [DEVLOG.md](DEVLOG.md)。

## 1. 项目背景与痛点

家里的东西越买越多，常见的几种情况：

- **忘了放在哪**：上次买的备用电池、药、充电线，要用的时候翻遍柜子也找不到。
- **过期了才发现**：药品、调料、护肤品放着放着就过期了，等发现时只能扔掉。
- **重复购买**：不知道家里还有存货，于是又买了一份。
- **信息不共享**：东西是一个人买的、放的，其他家人都不知道。

## 2. 目标用户

| 角色 | 特点 | 主要需求 |
| --- | --- | --- |
| 采购者（经常买东西的人） | 会主动录入 | 录入要快，字段不要太多 |
| 使用者（其他家人） | 很少录入，偶尔查找 | 能快速搜到东西在哪 |
| 长辈 | 不熟悉复杂操作 | 字大、颜色直观、步骤少 |

## 3. 核心功能

- 记录物品：名称、价格、功能/用途、购买日期、过期日期、放置位置、备注、照片
- 过期颜色提示：红 / 橙 / 黄 / 绿四档，同一档内越接近过期颜色越深，已过期单独标出
- 全家共享：通过邀请码加入同一个家庭，数据实时同步
- 查找：搜索、按位置或颜色筛选、按剩余天数排序
- 手机上像 App 一样使用：可以添加到主屏幕

## 4. 关键设计决策

| 决策 | 选择 | 理由 |
| --- | --- | --- |
| 产品形态 | 手机网页（PWA） | 不用上架审核、跨平台、一个链接就能分享给家人 |
| 数据存储 | Supabase 云端 | 家人之间需要共享；免费额度够用；自带登录和实时同步 |
| 剩余天数的更新方式 | 打开时实时计算 | 不依赖定时任务，数字永远准确 |
| 颜色分档 | 30 天 / 半年 / 一年三个分界点 | 对应“马上处理 / 近期留意 / 心里有数 / 不用操心”四种行动 |
| 颜色深浅 | 同档内越接近过期越深 | 让最急的东西最显眼 |
| 已过期状态 | 单独一档，写明过期天数 | 原始规则没覆盖，却是最需要处理的情况 |
| 登录方式 | 邮箱验证码 | 不需要记密码，对长辈更友好 |
