# Remember Me 作品集素材

> 这份文档是作品集的“原材料”，随项目迭代持续更新。详细的过程记录见 [DEVLOG.md](DEVLOG.md)。

## 1. 项目背景与痛点

家里的东西越买越多，常见的几种情况：

- **忘了放在哪**：上次买的备用电池、药、充电线，要用的时候翻遍柜子也找不到。
- **过期了才发现**：药品、调料、护肤品放着放着就过期了，等发现时只能扔掉。
- **重复购买**：不知道家里还有存货，于是又买了一份。
- **信息不共享**：东西是一个人买的、放的，其他家人都不知道。

## 2. 目标用户

| 角色 | 特点 | 主要需求 |
| --- | --- | --- |
| 采购者（经常买东西的人） | 会主动录入 | 录入要快，字段不要太多 |
| 使用者（其他家人） | 很少录入，偶尔查找 | 能快速搜到东西在哪 |
| 长辈 | 不熟悉复杂操作 | 字大、颜色直观、步骤少 |

（画像会根据家人试用后的反馈继续补充。）

## 3. 核心功能

- 记录物品：名称、过期日期、放置位置、类别；选填含价格、购买日期、用途、备注、照片
- 「记一件」顺序：先采集入口（拍包装 / 说话，识别能力迭代中）→ 名称与过期 → 位置与类别 → 补充项折叠
- 首页可调字号（三档，本机记住），方便长辈阅读
- 过期颜色提示：红 / 橙 / 黄 / 绿四档，同一档内越接近过期颜色越深，已过期单独标出
- 查找：关键词搜索（名称 / 位置 / 备注 / 说明）；按过期远近排序；按过期情况、类别、上传人筛选
- 多家庭：一人可加入多家，清单顶一键切换 / 新建 / 邀请码再加；可改家庭名字，退出前要确认

## 4. 关键设计决策

| 决策 | 选择 | 理由 |
| --- | --- | --- |
| 产品形态 | 手机网页（PWA） | 不用上架审核、跨平台、一个链接就能分享给家人 |
| 数据存储 | 腾讯云 CloudBase + PostgreSQL | 国内可用；体验版用 SQL 库存家庭与物品 |
| 登录 | 用户名 + 密码 | 不要微信执照、不用短信；家人账号在控制台创建，网页只登录不注册 |
| 剩余天数的更新方式 | 打开时实时计算 | 不依赖定时任务，数字永远准确 |
| 颜色分档 | 30 天 / 半年 / 一年三个分界点 | 对应“马上处理 / 近期留意 / 心里有数 / 不用操心”四种行动 |
| 颜色深浅 | 同档内越接近过期越深 | 让最急的东西最显眼 |
| 已过期状态 | 单独一档，写明过期天数 | 原始规则没覆盖，却是最需要处理的情况 |
| 界面风格 | 温馨暖色、手机优先 | 大触控、主操作不被悬浮控件挡住；过期颜色仍表达紧急程度 |
| 上线方式 | PWA + CloudBase 静态托管 | 国内访问稳；默认域名通常已在白名单，少踩跨域套餐坑 |
| 默认域名风控 | 试用先过风险页；正式用自定义备案域名 | 见下方「上线坑」；重传静态包解决不了 |
| 自定义域名 | `https://remembermezz.xyz`（已上线） | 正式入口；避开默认域名下载/风险页 |

## 4.1 上线坑：默认域名变成下载网页

**现象**

家人用默认域名（`*.webapps.tcloudbase.com` 等）打开时，有时直接下载 `index.html`，有时先看到腾讯云「风险提醒」中间页。

**原因（产品/技术判断）**

不是前端打包错误。腾讯云对未备案默认域名做合规限制：部分请求会加 `Content-Disposition: attachment`（强制下载）；浏览器正常进入则可能先出风险页。微信内打开、Cookie 过期、换设备后更容易复现。

**临时方案**

系统浏览器地址栏打开 → 过风险提示 → 小范围家人试用可接受。

**根本方案**

ICP 备案自定义域名 + CloudBase 绑定；并把新域名加入安全来源。正式入口已是 `https://remembermezz.xyz`（备案、SSL、DNS、网关均已通；手机/电脑可正常打开）。作品集叙事可强调：选国内云降低跨域成本，同时认清「默认域名只适合开发测试」。

## 6. 数据与反馈

已开始收集家人原话：

- 产品经理朋友：位置希望有桌子、收纳柜一类的图，更直观。
- 妈妈：录入要一个个打字麻烦；年纪大看不清，希望拍照识别保质期/生产日期。

还可继续记：家里录入件数、因颜色提醒在过期前用掉的件数。

## 7. 反思与下一步

- 已能本地登录、建家庭、记物品；一人可进多家并切换，也能改家庭名字、确认后退出；清单支持关键词搜索；记一件页已按「先采集再核对」重排，字号可调。
- 下一步按计划：位置带图 → 文字 AI 填表（hy3 已开通）→ PaddleOCR 拍包装 → SenseVoice 语音。
- 网页自助注册被腾讯云拦住，家庭场景用控制台开号更合适，但要提前帮长辈建好账号。
- Vercel 免费域名国内不稳，且自定义跨域白名单可能要付费，故前端托管与后端同落腾讯云。
- **默认域名坑**：打开变成下载或风险页，是平台对未备案域名的风控，不是包传错。正式入口已切到 `https://remembermezz.xyz`（详见 §4.1）。
