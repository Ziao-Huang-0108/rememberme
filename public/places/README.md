# 位置小图（步骤 2 用）

请把图画好后放到这个文件夹，文件名按下面来（SVG 或 PNG 都行，优先 SVG）。

| 文件名 | 表示 |
| --- | --- |
| `fridge.svg`（或 `.png`） | 冰箱 |
| `cabinet.svg` | 柜子 / 收纳柜 |
| `drawer.svg` | 抽屉 |
| `table.svg` | 桌子 |
| `medbox.svg` | 药箱 |
| `shelf.svg` | 架子 |
| `other.svg` | 其他 |

建议：

- 单色或低饱和暖色线稿/剪影，风格统一
- 画布约 **128×128** 或 **256×256**，透明底
- 不要用表情符号凑数；留白适中，手机列表缩略图也能看清

发我时可以说「图放好了」，或直接把文件丢进对话 / 这个文件夹。
