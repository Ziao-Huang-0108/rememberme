# Remember Me
> 移动端物品台账PWA网页，一站式管理物品开销、存放位置、使用频率与临期提醒。

Remember Me is a mobile-friendly web app that tracks your belongings' costs, storage locations, usage frequency and expiration dates, with color-coded alerts for expiring items.

## 功能
- 物品信息记录：名称｜价格｜购买日期｜存放位置｜备注｜实拍照片
- 过期预警：自动计算剩余天数，绿/黄/红三色标记临期状态
- 使用频率标记（每周/每日）
- 支持添加到手机主屏幕，像App一样使用
- 本地存储保存数据

## 🛠技术栈
Vite + React + TypeScript + TailwindCSS
